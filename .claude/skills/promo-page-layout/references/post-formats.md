# 포스트 포맷

SNS·커뮤니티·공지용 단일 이미지. 페이지와 달리 스크롤이 없으므로 **한 장 = 한 메시지**, 블록 5개 이하.

## 캔버스·안전 영역

| 포맷 | 캔버스 | 안전 영역 | 비고 |
| --- | --- | --- | --- |
| `post-square` | 1080×1080 | 여백 60 (960×960) | 피드 기본. 썸네일 300px 에서도 타이틀이 읽혀야 함 |
| `post-portrait` | 1080×1350 | 여백 60 | 피드 세로. 비주얼 비중을 키울 때 |
| `post-story` | 1080×1920 | 좌우 60, 상단 250, 하단 300 | 상단 프로필/진행바, 하단 답장 UI 회피. 이 영역엔 배경만 |
| `post-notice` | 860 폭, 높이 가변 | 여백 50 | 공식 카페·커뮤니티·게임 내 공지 이미지. 본문 텍스트 위주 |

## 블록 비율 (안전 영역 높이 기준, 존재하는 블록끼리 정규화)

| 블록 | 비율 | 최소 높이(안전 높이 대비) | 내용 |
| --- | --- | --- | --- |
| brand-bar | 고정 80 | — | 게임 로고 좌측, 이벤트 라벨 우측 |
| title | 0.22 | 14% | 2줄 이하. 글자 높이 ≥ 안전폭의 8% |
| subcopy | 0.08 | 5% | 1줄 |
| visual | 0.40 | 26% | KV/캐릭터/아이템. `photographer-layout` 이 크롭 결정 |
| reward-strip | 0.16 | 11% | 보상 아이콘 3~5개 행 + 수량 |
| period | 0.07 | 4.5% | 기간. 배경과 분리되는 띠 권장 |
| cta | 0.10 | 7% | 참여 버튼 문구 또는 해시태그. 스토리는 하단 안전선 바로 위 |
| text | 0.12 | 8% | 본문 |
| notice | 0.08 | 5% | ※ 한 줄 |
| footer | 고정 60 | — | 저작권·해시태그 |

`post-notice` 는 비율 대신 고정 높이: title 140 / subcopy 60 / visual 폭×0.56 / reward-strip 260 / period 60 / cta 100 / text 200 / notice 120.

## 구성 규칙

- 읽기 순서는 타이틀 → 비주얼 → 보상/기간 → CTA. 비주얼이 주인공인 티저만 비주얼 → 타이틀.
- 타이틀과 비주얼이 겹칠 땐 비주얼 블록 안에 타이틀 안전 영역(상단 35%)을 남긴다. 스크립트는 겹침을 허용하지 않으므로
  겹침 연출은 `visual` 블록 하나로 잡고 `slots` 에 타이틀 안전 영역을 기록한다.
- 본문 최소 크기: 1080 캔버스에서 28px, 공지(860)에서 24px. 행간 1.4 이상.
- 카드뉴스(여러 장)는 장마다 brief 를 따로 만들고 `series: { index, total }` 을 넣는다. 첫 장 = 후킹, 마지막 장 = CTA.
- 스토리는 상단 250·하단 300 에 정보 블록을 두지 않는다. 스크립트가 이 침범을 경고한다.
