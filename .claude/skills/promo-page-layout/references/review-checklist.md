# 레이아웃 단계 자가 검수

완성 이미지 채점은 `nexus-design-evaluator`(`promotion` / `promotionMobile` / `promotionKv` / `brandwebSub`)가 한다.
이 체크리스트는 그 평가 키 10개를 **레이아웃 계약 단계에서 미리** 점검하는 용도다. 점수를 예측하거나 매기지 않는다.

| 평가 키 (프로모션) | 레이아웃에서 확인할 것 | 실패 신호 |
| --- | --- | --- |
| impression 첫 화면 흡입력 | 히어로 안에 타이틀·캐릭터·기간이 모두 있고 타이틀이 KV 폭의 ≥ 1/3 | 타이틀 블록이 콘텐츠 폭보다 작음, 히어로에 기간 없음 |
| brand 브랜드·이벤트 톤 | 문법이 게임 관행과 맞음 (리니지=refine/scroll, 블소=osangseu) | 게임과 다른 문법을 근거 없이 선택 |
| concept 캠페인 이해도 | 첫 섹션이 캠페인의 핵심 보상/제작식 | 첫 섹션이 패키지·유의사항 |
| color 보상 매력도 | 보상 카드가 콘텐츠 폭을 가득 채우고 아이콘 슬롯이 카드의 ≥ 45% | 카드 6열 이상, 아이콘 슬롯 작음 |
| layout 보상 구조·조건 | 제작식은 A+B→C 한 행에, 조건형 보상은 [조건]→[보상] 순서 | 재료와 결과가 다른 행 |
| typography 정보 위계 | 섹션 타이틀 72 > 소제목 44~60 > 본문 22~34 > 안내 18~20 (3000 기준) | 같은 크기 반복, 배지가 타이틀보다 큼 |
| conversion 참여 동선·CTA | 첫 섹션 뒤와 페이지 끝에 CTA, 모바일은 sticky | CTA 0개, 히어로 안에만 있음 |
| readability 정보 가독성 | 텍스트·부품이 1100 안, 안내문은 컨테이너 밖 | 안전폭 이탈 경고, 컨테이너 안 ※ 문구 |
| flow 스크롤 리듬 | 섹션 간 170(±40), 섹션 내 블록 간 40~60, 같은 타입 연속 없음 | 섹션 간격 불규칙, 컨테이너 두 개 연속 |
| detail 운영 신뢰성 | 기간·유의사항·확률 안내 블록 존재, 마지막 섹션이 notice | 유의사항 없음, 기간 자리표시자 없이 비어 있음 |

모바일 추가 확인: 본문 ≥ 28px(750 기준), 터치 타깃 ≥ 88px, 하단 120 sticky 영역과 마지막 블록 비겹침, 카드 3열 이하.

브랜드웹 서브 확인: CNB 54 아래 상단 여백 136, 좌측 메뉴 310 과 콘텐츠 비겹침, 하단 여백 156, 콘텐츠 박스 2장 460×300.

포스트 확인: 블록 ≤ 5, 타이틀 ≥ 안전폭 8% 높이, 스토리 상·하단 UI 영역 비어 있음, 한 장에 메시지 하나.
