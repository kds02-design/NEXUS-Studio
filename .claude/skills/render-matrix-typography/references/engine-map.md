# Render Matrix typography map

Local sources:

- `src/apps/RenderMatrix/services/promptCompiler.js`
- `src/apps/RenderMatrix/hooks/useRenderPrompt.js`
- `src/apps/RenderMatrix/constants/materials.js`
- `src/apps/RenderMatrix/constants/presets.js`

Mandatory defaults:

- `editBudget=Locked`
- strict original-letterform and alpha-silhouette lock
- `cameraLens=Telephoto`
- `projectionDepth=None`
- surface/material/lighting changes only
- no font substitution, outline growth, counter filling, horizontal squeeze, or extra text

Use steel or polished silver for the main season title and restrained matte/antique gold for the compact eyebrow when matching the Season 4 pond key visual.
