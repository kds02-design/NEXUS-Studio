# Blade & Soul profile guide

Use the live Figma guide `BS_banner_GUIDE__` in file `yfrEN3GMD2RPqs7I2MbryK` for BNS brand, channel, and frame rules when available. Confirm page and node IDs live rather than trusting cached IDs. Layout selection is governed by the shared Aion+BNS 40-sample pool, not by a BNS-only subsection.

## Brand routing

- Classic or Live campaigns use the classic BI.
- Current NEO campaigns use the current NEO BI. A legacy NEO campaign requires its supplied approved legacy BI or repeat master.
- Specialized campaigns use the approved NEO BI plus the specialized badge.
- Show only one BI generation and at most one channel badge.
- Keep BI and badge on separate editable layers; the badge is above the BI.
- Do not regenerate, trace, recolor, crop, or flatten official BI or badge assets.

For 1200×628 or 1200×630, use the selected channel placement stored in the JSON profile unless a current approved live frame or repeat master supplies an explicit override. Protect `x=840..1200, y=0..170` from faces, title-critical strokes, and item identity cores.

## Frame family

- 1180 Notice is the evaluated full-text master.
- 1200 Facebook contains the full information stack and routed official logo.
- Purple, PC/MO, and EventON are independent image-led hero crops, not reduced copies.
- Toast reserves its top 70 px for transparency and omits information and items by default.
- Ingame is transparent character-only.
- List is a face or identity-core crop at native size.

Use the source character and aligned FX on identical canvases. Channel badges are omitted from Toast, Ingame, and List unless a later approved master explicitly contains one.

## Live authority

The approved live frame overrides measured defaults. Record `biGeneration`, `channelBadge`, asset source, and live bounds in the game-profile lock and frame manifest.
