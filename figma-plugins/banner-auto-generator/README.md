# NEXUS Banner Auto Generator

1. Figma 데스크톱에서 `Plugins > Development > Import plugin from manifest...`를 선택합니다.
2. 이 폴더의 `manifest.json`을 선택합니다.
3. Banner Creator에서 `Figma 자동 생성 파일`을 내려받습니다.
4. 플러그인을 실행하고 JSON을 불러온 뒤 `사이즈별 배너 생성`을 누릅니다.

큰 가로형은 전체 레이어를 유지합니다. 정사각·토스트·인게임 규격은 핵심 이미지와 타이틀 중심으로 재배치하며, 72×40은 배경·타이틀·배지만 유지합니다.
